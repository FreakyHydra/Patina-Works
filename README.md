# PatinaWorks

A Minecraft mod about building and restoring with patina — the beauty that comes with age and use.

PatinaWorks adds a progression of machines and tools centered around a **Patina Workbench**, with a built-in **Patina Ledger** recipe browser so you never need JEI or EMI.

## Current Milestone: Recipe Index

- Patina Ledger — a held book that opens a read-only recipe viewer
- Patina Workbench — early crafting station
- Custom items: Copper Plate, Copper Gear, Copper Rivet, Engineer's Hammer
- All crafting recipes for the `patinaworks` namespace viewable in-game
- Search, scroll, and variant navigation for recipes

Built for Minecraft 1.21.1 with NeoForge 21.1.244.
