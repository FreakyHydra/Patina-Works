# Patina Works

**Build the Copper Age.**

Patina Works is an early-development Minecraft survival and engineering overhaul built around copperworking, physical machinery, exploration, and settlement progression.

The long-term goal is to create a self-contained survival experience that feels like its own game inside Minecraft.

Patina Works will also feature **Coda**, the player's persistent companion, guide, quest handler, and heart of the project.

> Patina Works is currently in active early development. Features, recipes, names, and designs may change significantly.

## Current Milestone: Recipe Index

The first playable foundation currently includes:

- **Patina Ledger** — a held book that opens the built-in recipe index
- **Patina Workbench** — the first Patina Works crafting station
- **Copper Plate**
- **Copper Gear**
- **Copper Rivet**
- **Engineer's Hammer**
- Searchable Patina Works recipe display
- Recipe scrolling and variant navigation
- A dedicated Patina Works creative tab

The Ledger currently displays crafting recipes from the `patinaworks` namespace. Support for future anvil, casting, pressing, grinding, and machine recipes will be added as those systems are developed.

## Next Milestone: Manual Copperworking

The next gameplay loop will introduce the first physical production process:

```text
Copper Ingot
→ Stone Anvil
→ Engineer's Hammer
→ Copper Plate
```

This will replace the temporary crafting-table recipe for Copper Plates and give the Engineer's Hammer its first real purpose.

## Project Status

Patina Works is currently an experimental open-source project.

It is not yet ready for a normal survival playthrough or public release. The current build exists to test the technical foundation, recipes, user interface, and early gameplay systems.
